## Descripción del mapa

El mapa contiene todo el cantón de nicoya, extraído de geo_cantones.shp. 
Inlcuye la división distrital.

El mapa contiene información puntual sobre:
- Hospitales
- Gasolineras
- Poblados 
- Hoteles 
- Escuelas
- Clinicas 
- Aeropuertos
- Bancos

Cada punto se representa con un símbolo diferente para que sean más fáciles de diferenciar.

El mapa contiene información lineal sobre:
- Calles
- Ríosi
- Carreteras

El mapa contiene información poligonal sobre:
- Edificios
